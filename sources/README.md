# 外部来源接入

市场在 DSH 内查询目录、读取文档并下载资源。自动发现以受支持的来源适配器为边界，不接受任意抓取地址。

| 来源 | 当前覆盖 | 更新方式 |
|---|---|---|
| DSH 官方 npm | 4 个插件，关联 /plan、/compact、/goal；固定 0.1.5-rc.2 | 更新指定包与命令 |
| Anthropic Skills | 扫描实际顶层 Skill 目录，当前 19 项中收录 12 项 | 宿主运行期间每 6 小时自动检查，可暂停和手动刷新 |
| OpenAI Skills | 扫描 `skills/.curated/<name>/SKILL.md`，不导入 Codex 内部 `.system` 目录 | 每 6 小时检查，可暂停和手动刷新 |
| MCP 官方 Registry | 分页读取所有最新活动记录，按传输与格式筛选 | 每 6 小时检查；不限定发布者名单 |
| npm DSH 社区扩展 | 分页搜索 `dsh-plugin`、`dsh-theme`、`dsh-std` 标记 | 每 6 小时检查；安装前再核验真实清单 |
| 本项目 GitHub 索引 | `catalog/registry.json` 中经审核合并的六类记录 | 固定当前 main 提交读取索引，自动同步 |

`definitions.mjs` 中已知资源名称只用于展示翻译，npm、MCP 和 Skill 扫描均可发现未预设的条目。2026-09-14 的 npm 实测扫描 4,887 项，收录 4,844 项，其中 5 项由作者标记为主题。MCP 的一次完整实测遍历 318 页、31,784 个身份；收录数以当前校验结果为准。这些是目录候选，并不代表已通过 DSH 运行验收。

GitHub 索引支持插件、Skill、MCP、Slash、Prompt、主题；Slash 必须明确所属插件与命令，不从 README 猜测。当前包含 8 份 Prompt 和 3 个已核对的官方命令声明。主题以作者明确的资源类型识别，不把通用 Skill 的 theme-factory 归为 DSH 主题。任意 GitHub 仓库搜索、用户自定义 URL 和本地模型仍不在当前自动扫描范围。

## 更新与失败处理

设置页显示扫描、收录和跳过数量、原因、最近成功时间及自动检查状态。失败保留旧目录，30 分钟后重试；暂停只阻止后续检查，当前请求允许完成。卸载市场时取消其网络检查。手动刷新在后台执行，页面可继续使用。首次使用随包目录，运行时缓存保存在 `DSH_HOME/community/sources/catalog-cache.json`；新增来源会迁移旧缓存并保留原修订和暂停设置，损坏缓存不覆盖。

npm 每页最多 250 项，页间间隔 1.2 秒；MCP 每页最多 100 项。页数上限、重复游标、分页身份冲突和网络失败均不能变成成功的部分结果。目录没有事务快照承诺。资源列表每批显示 48 项，MCP 完整定义按需读取；Star 查询只接受当前页面最多 60 个资源 ID。跨源重复包优先采用社区审核记录，并保留别名。

内容与文件变化才增加 Skill 修订号，仓库无关提交不制造更新。收藏保持原版，需要明确选择替换。核实移除请求后，在 `removals.json` 记录 ID、理由和 Issue；后续发现与随包更新均排除该资源。

维护者运行 `node sources/update.mjs` 更新随包目录，再执行 `npm run verify`；不要直接修改生成目录。发行物只携带最多 100 个 MCP 起始条目，不携带完整扫描报告；安装后自动扫描仍读取全部分页并保存完整本机缓存。这样避免把数万份服务定义打入安装包。`node sources/check.mjs` 可离线验证发现报告、正文散列和 Slash 父插件关系。

## 收录与下载条件

社区审核以本项目 [贡献指南](../CONTRIBUTING.md) 为准，外部目录提供候选来源与参考经验，其收录决定不等于本项目审核结果。下面的限制是当前适配器的技术支持范围，不作为所有资源的统一质量标准；不符合当前适配器的资源可先通过 Issue 提议，不会绕过现有校验直接进入目录。

Skill 适配器检查 SKILL.md 元数据、完整目录及已核验的 Apache-2.0／MIT 许可文本。许可散列白名单只标识许可文本，不限定资源名称；来源不明或尚未核对的定制许可会显示排除原因。发现阶段读取指令与许可正文，伴随文件按 Git 树固定散列，获取 ZIP 时逐一验证实际字节。

最多扫描 100 个 Skill；每个目录最多 150 文件，单文件 1 MiB、合计 4 MiB，正文最多 50,000 字符。拒绝路径穿越、符号链接、子模块和不完整树。网络或完整性错误使整次更新失败，不发布半份目录。阈值是当前实现限制，不是资源质量判断。

Skill ZIP 保留原始文件及许可，逐文件校验 Git blob SHA-1 和长度，并带 SOURCE.json。插件 TGZ 校验官方 npm SHA-512 SRI。MCP 导出发布者服务定义，Slash 指向所属插件；均不自动安装、加载、连接或执行。

## 作者文档

详情的“概况”是简要导览，“作者文档”保留来源原文。Skill 展示固定提交的 SKILL.md，若有 README 也列出；插件读取自身目录 README；Slash 展示所属插件文档。MCP 若只能定位仓库当前文档，会注明可能与所选版本不同。缺少 README 不使用生成内容替代；网络失败提供重试。

README 按需读取，按资源版本缓存 6 小时，包含原文链接及提交。动态读取的文档保留原作者权利，不成为项目原创文件。展示 Markdown 时不执行 HTML、脚本或加载远程图片。

文档默认优先匹配界面语言，再回退英文；识别 README.zh.md、README.zh-CN.md、README_CN.md 等命名，三份上限不会挤掉中英日首选文件。用户可通过 DSH 已配置模型主动翻译，明确确认消耗该模型 Token 额度。译文独立显示，不写回原资源；详细调用及用量边界见 [架构](../docs/ARCHITECTURE.md)。

网络请求访问 GitHub API、原文服务、npm 和 MCP Registry，禁止重定向，单次响应最多 4 MiB。默认匿名；配置本机加密令牌后，仅 GitHub API 的 GET 请求携带认证，详见 [GitHub 连接](../docs/GITHUB_CONNECTION.md)。缓存不包含离线安装包。许可和版权见 [第三方清单](../THIRD_PARTY_NOTICES.md)；Prompt 投稿见 [目录说明](../catalog/README.md)。
