# DSH Marketplace

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja-JP.md)

**DeepSeek Harness 内でプラグイン、Skill、MCP、Slash、Prompt、テーマを探し、利用・管理できる**コミュニティプロジェクトです。独立して開発しており、画面は中国語・英語・日本語に対応します。マーケット用アカウントは不要です。

![DSH Marketplace](docs/images/marketplace.png)

*開発画面です。リソースの文書は原文を保持します。*

## 開発状況

**`v0.2.0-alpha.1`：初期プレリリース。** 検証環境は Windows / Node.js 24 / DSH 0.1.5-rc.2 です。ローカル検証は公式パッケージ、実ホスト画面、リソース操作を対象とし、標準管理は削除準備後のマーケット削除を含む 5 回の独立起動で検証しました。配布物は [Releases](https://github.com/QT7-C23/DSH-Marketplace/releases)、オンライン検証の実際の結果は [Actions](https://github.com/QT7-C23/DSH-Marketplace/actions) を確認してください。npm には公開していません。

検証基準は **Windows、Node.js 24、DSH 0.1.5-rc.2** です。リソースごとの結果を区別し、他のホスト版への互換性は推定しません。

## 利用できる機能

| 種類 | 操作と範囲 |
|---|---|
| プラグイン | npm の固定版、宣言、互換性を確認し、DSH 公式 CLI で導入・更新・削除します。ネイティブ入口は profile 設定で有効化・無効化できます。保護対象と逆依存の検査が操作を制限します。 |
| Skill | 固定 Git コミットの原ファイルを確認して導入し、DSH のネイティブ Skill サービスで読み込み・呼び出します。有効化、無効化、更新、ファイルを保持する削除、復元に対応します。外部で変更されたファイルや管理外のファイルは置き換えません。 |
| MCP | 固定版の完全なサーバー定義から接続を選び、宣言された値を入力します。HTTPS Streamable HTTP と固定 npm 版の stdio の設定・有効化・無効化・削除に対応します。ツール登録は継続的な正常動作を意味しません。 |
| Slash | 現在の会話で親プラグインが提供するコマンドを実行します。実際の `/plan` と `/plan off` で入力下書きと参照の保持を確認しました。コマンド固有の効果・要件は引き続き適用されます。 |
| Prompt | 原文をプレビューし、本文・参照・添付を保持して DSH の下書きへ追記します。追記だけでは送信しません。 |
| テーマ | npm テーマを検出し、パッケージ管理から適用・削除します。実際の 3 パッケージで異なる結果を確認しました。汎用のテーマファイル取り込み機能はありません。 |

標準コンポーネントは任意の **dsh-std アダプター**と、マーケットが管理する単一の検出 Loader を利用します。初回の管理移行では全標準コンポーネントが再読み込みされる場合があり、実行前に表示します。公開 SDK では旧バッチの後処理完了を証明できないため、同じプロセスは **unknown／restart-required** のままで、代替アダプターが active でも次の有効化・無効化を拒否します。DSH を完全に停止して起動してください。その後の安定した起動では、切り替えは次回起動の設定だけを保存します。再起動後はブラウザーも更新します。モジュールキャッシュのホット交換や自動復旧はありません。[拡張管理](docs/EXTENSION_MANAGEMENT.md)

テーマの実測では、**Galactic Opera 0.2.1** は適用できましたが、文字のコントラストに **1.04:1** の警告があります。**Machine 0.1.3** は起動できませんでした。**Bloom 0.12.0** は既定の Mist と、キーボードでメニューを開いて選ぶ Cinnabar が利用できましたが、マウスで開けない不具合とローカルの 404 ポーリングがあります。限定した検証結果であり、全面的な互換性の保証ではありません。[互換性の詳細](docs/COMPATIBILITY_AND_THEMES.md)

## 検出と更新

6 つの配布元をまとめ、重複を除いて表示します。

| 配布元 | 2026-09-14 の観測 |
|---|---|
| DSH 公式モジュールとコマンド | ホスト基準版に固定した 4 モジュールと 3 コマンド |
| Anthropic Skills | 19 ディレクトリを調べ、12 件を収録 |
| OpenAI Skills | 39 ディレクトリを調べ、30 件を収録 |
| npm コミュニティ拡張 | 4,887 候補を調べ、4,844 件を収録。うちテーマは 5 件 |
| 公式 MCP Registry | 一意なサービス 31,784 件を調べ、30,116 件を収録 |
| 本プロジェクトの審査済み GitHub 索引 | 6 種類に対応。`main` に審査・マージされた項目だけが同期対象 |

完全な実行時スキャンで **35,017 件の統合項目**を観測しました。これは当日の収録条件に基づく値で、件数や全項目の利用可能性を保証しません。配布元間には重複があり、検出は導入や実利用の検証とは別です。公式 4 モジュールはホストやプリセットに含まれる場合があり、独立したコミュニティ bundle が 4 個あるという意味ではありません。

確認したソースの初期カタログには、配布元をまたぐ重複排除前で **4,907 件の記録**があります。配布用 MCP は**最大 100 件**に制限しますが、現行の初期カタログが 100 件を含むという意味ではありません。実際の同梱内容は最終パッケージ報告に従います。実行時には MCP 全体をページ取得します。

自動検出は **6 時間**ごと、失敗後は **30 分**で再試行します。設定には配布元ごとの停止・再開、手動同期、スキャンと除外理由があります。DSH 公式の配布元は固定版を維持します。ページの失敗・不完全な取得はその配布元のスキャン全体を無効にし、最後の完全なキャッシュを保持します。終了時には実行中の取得を取り消します。審査済み変更はマージ後の成功した同期で届きますが、最初の公開リモート同期は公開後の検証待ちです。

## クイックスタート

ソース開発には Node.js 24+、npm、パッケージ操作時に PATH 上で使える pnpm、ネットワーク、Windows の Microsoft Edge が必要です。

```powershell
npm ci
npm ci --prefix integration --ignore-scripts
node integration/build.mjs
node integration/host.mjs web --dump-config
node integration/set-plugin.mjs on
node integration/host.mjs web --port 4180 --no-open
```

`artifacts/dsh-integration/runtime/url.txt` の非公開認証 URL を開き、**继续**、**稍后配置** の順に選びます。サイドバーの **扩展市场** を開き、**设置** で言語を変更します。閲覧にモデルキーは不要です。停止は `Ctrl+C` です。

Prompt や Slash を使うには `artifacts/dsh-integration/runtime/workspace` を追加し、会話を作成します。ランチャーは開発用の設定とデータを分離しますが、OS サンドボックスではありません。[ホスト設定](integration/README.md)

依存関係の導入後、独立した TGZ をビルドできます。

```powershell
npm run package
```

候補ファイルは `artifacts/releases/dsh-market-integration-0.2.0-alpha.1.tgz` を予定しています。実際のパスとチェックサムは `package-result.json` を確認してください。公式 CLI のコマンドは [パッケージガイド](docs/PACKAGE_INSTALLATION.md)、今後の公開ファイルは [GitHub Releases](https://github.com/QT7-C23/DSH-Marketplace/releases) を参照してください。

## データと指標

| 指標 | 意味 |
|---|---|
| GitHub Star | 出典リポジトリ全体の値。鮮度を表示 |
| npm ダウンロード | パッケージ全体に対する npm の `last-month` 期間の値。開始・終了日と最新／古い／取得不可を表示。マーケットでの導入数や特定版の利用者数ではありません |
| ローカル DL | ローカル SQLite サービスがファイルを用意できた回数。同じリクエスト ID は重複計上せず、保存・導入の完了は推定しません |
| お気に入り・評価 | このブラウザー／サイトの個人データ。公開総数や全体平均ではありません |

お気に入り、帰属付き下書き、評価、表示言語はブラウザーに保存されます。サイトデータの削除で消え、ポート変更で保存範囲が変わります。サーバーのキャッシュと操作記録は `DSH_HOME/community/` に保存されます。画面では秘密情報を除いた直近 20 件の profile 操作情報を表示します。復旧にはローカルのログ、バックアップ、設定の確認が必要です。旧アカウントと非公開テーブルは保持し、公開しません。

作者の文書は出典を保持し、README は表示言語、次に英語を優先します。**翻訳は設定済みの DSH モデルを選び、明示的に開始したときだけ実行します。Token を消費し、失敗・取り消しでも課金される場合があります。** 原文は残り、1 回 24,000 文字までで自動分割・再試行は行いません。

任意の [GitHub 読み取りトークン](docs/GITHUB_CONNECTION.md) は API 枠に使用し、Windows でローカル暗号化します。投稿は GitHub 自身のアカウントを使います。閲覧やローカルのお気に入りにマーケットのログインは不要です。

[貢献ガイド](CONTRIBUTING.md)と[6 種類のカタログガイド](catalog/README.md)に従ってください。画面の汎用出力は**提案専用**です。メンテナーが `catalog/resource-entries.json` に審査済みの種類別情報を補完し、Prompt は `catalog/prompts/` に置きます。`node catalog/build.mjs` と `npm run verify` を実行し、審査・マージします。生成索引を手作業で変更しないでください。Issue の提案時には実行用の項目が不足していても構いませんが、必要な情報なしでは公開カタログに入りません。

著作者・メンテナー・権利者は侵害の主張なしで [掲載取り下げフォーム](https://github.com/QT7-C23/DSH-Marketplace/issues/new?template=04-resource-removal.yml)を利用できます。詳細画面にも入口があります。審査済みの `sources/removals.json` は別名と安定した識別子に基づいて全配布元へ適用し、最後の成功した方針を失敗・再起動後も保持します。個人のコピーや導入済み内容は削除しません。設定画面で既知の判断を確認できます。

## 標準互換性と削除準備

固定版 dsh-std adapter 0.1.1-rc.3 には上流の制限があります。CommandRuntime を要求するコンポーネントの起動後、後続コンポーネントが接続交渉で失敗する場合があります。コマンド提供側の検証合格は、この組み合わせの互換性を保証しません。実際の構成を確認してください。

標準コンポーネントを管理したマーケットを削除する前に、DSH を停止し、同梱の保守プレビューを実行してください。DSH_HOME は実際の絶対パスに置換します。上流の自動検出を復元するため、無効化した標準コンポーネントが再び起動する場合があります。不要なパッケージは先に公式 CLI で削除してください。プレビューを確認後、同じコマンドに `--confirm <fingerprint>` を追加します。表示された無効パッケージの再有効化に同意する場合のみ `--enable-disabled` も追加してください。`not-managed` は確認不要です。準備成功後に公式削除を実行します。他の設定を保持し、バックアップを記録します。

```powershell
node "<DSH_HOME>\profiles\web\node_modules\dsh-market-integration\integration\maintenance.mjs" prepare-uninstall --home "<DSH_HOME>" --profile web
```
