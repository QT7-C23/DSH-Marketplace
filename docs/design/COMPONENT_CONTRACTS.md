# 市场组件合同

| 组件 | 任务 | 状态与验收 |
|---|---|---|
| Button / Field | 使用原生控件完成操作或填写 | 标签、必填、焦点、禁用、错误；窄屏换行 |
| ResourceCard | 名称、作者、摘要、版本、许可、来源、使用方式与指标 | 单一详情入口；摘要三行、详情全文，未知状态不冒充已安装 |
| HostPresence | 读取与目录模块匹配的宿主和预设状态 | 已配置不等于已加载；默认预设不等于当前会话；失败未知、可重试、不写配置 |
| ResourceFacts / UsageGuide | 版本信息与五类使用步骤 | 目录核验日期不冒充上游发布日期；下载和实际启用分开 |
| ResourceStats | 本机下载、仓库 Star、个人收藏与评分 | 区分未知、零、读取中与缓存，不混用统计口径 |
| Rating | 保存自己的 1–5 分评价 | 本机持久化、可改可清除；存储失败不丢选择 |
| Editor | 为五类资源准备 GitHub 投稿 | 保留作者、编号、许可、语言和草稿；导入只读取文本 |
| Dialog | 预览投稿或确认移除副本 | Esc 关闭、焦点归还，窄屏可滚动 |
| Sources | 语言和来源更新配置 | 读/写状态、暂停持久化、扫描报告、失败保留上次目录 |
| ResourceDocumentation | 阅读来源的 README / SKILL.md / Prompt | 界面语言优先、英文回退、手动切换；缺失与失败区分、来源与提交、HTML 不执行 |
| DocumentTranslation | 选择模型并主动翻译当前文档 | 开始按钮明确 Token 消耗；取消、手动重试、原译文切换、真实用量、旧结果隔离；不自动调用 |
| Prompt | 填参、预览并追加宿主草稿 | 会话/草稿变更拒绝旧预览，文本/引用/附件保留，不发送 |

实现位于 integration/plugin/market；所有状态由公开控制器合同或文档读取合同提供。复用薄 HTML 控件与宿主语义主题，页面不直接操作其他模块状态。历史 prototype 仅为交互设计对照，不代表当前账户或安装能力。详见 [设计系统](DESIGN_SYSTEM.md) 和 [架构](../ARCHITECTURE.md)。
