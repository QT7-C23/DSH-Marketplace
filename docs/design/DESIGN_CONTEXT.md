# 市场设计上下文

更新：2026-09-14。甲方要求保留市场横幅、减少模板化装饰、取消市场登录、加入用途分类、三语设置和作者 README，并参考 Awesome DSH Plugin 与 dsh-market 的信息组织和安装体验。

| 项目事实 | 当前选择 |
|---|---|
| 主要任务 | 发现适用资源，阅读原文，获取并保存明确版本 |
| 导航 | 发现 / 我的资源 / 设置；分享入口在页头 |
| 分类 | 六种资源类型与用途分类分开；主题归入设计用途，未收录时显示真实空状态，其余未知项归入通用 |
| 投稿 | 表单收集作者、许可、原文语言和来源，导出后向 GitHub 提交 |
| 身份 | 不建设市场账号；署名不当作身份核验 |
| 内容 | 短概况用于筛选，详情分概况与作者文档；原文不改写 |
| 设置 | 中英日界面语言，来源检查开关和手动更新 |
| 统计 | 本机下载次数、仓库 Star、本机收藏状态、个人评分，分别标明 |
| 视觉 | 宿主主题与字体，完整边界卡片、清晰的版本与使用状态、单色暖底横幅 |
| 宿主状态 | 区分宿主和预设；已配置、已加载、停用、条件启用、失败分别展示 |

横幅使用真实 Prompt 原文摘录。名称与作者、摘要、类型与用途、使用方式与许可、来源与统计依次展示。卡片摘要至多三行，详情保留完整摘要和作者文档。详情侧栏集中获取、宿主状态和版本信息；窄屏优先显示获取区，打开详情回到标题。

保留浅色、深色、390px 窄屏、长内容、空状态、失败重试、对话框 Esc/焦点和宿主字号验收。参照 Project Design Base 的任务清晰、层级、平台惯例优先顺序；不把独立原型或 Figma 当作实际接线证据。
