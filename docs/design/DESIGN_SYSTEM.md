# 市场设计系统

宿主 DSH 的 `--dsw-alias-*` 颜色、字体与正文字号为运行时事实源。界面样式限定在 `@scope (.community-ui)`；不改变宿主全局按钮、输入框或布局。

- 页面主导航为发现、我的资源、设置；主标题 20px，正文 14px，辅助信息 12px。
- 资源卡片为完整边界、12px 圆角；可用市场宽度至少 1080px 时三列，480–1079px 两列，390px 窄屏单列。版本、许可、来源与使用方式可见，统计独立一行；名称不截断，摘要最多三行，详情显示全文。
- 推荐横幅为暖色语义混合背景，8px 圆角、真实原文摘录，无旋转纸片或阴影装饰。搜索、类型或用途筛选时收起。
- 详情标题为 28px，完整摘要常驻；概况包含按类型区分的使用步骤，另设作者文档。右栏为 300px 的获取、宿主状态与资料区；780px 以下移到正文前。切换资源回到标题，避免继承目录滚动位置。
- 宿主状态使用公开 Loader 和 AgentPresets 数据，按作用范围分别列出；模块匹配不等于当前会话可用。失败显示未知并允许重试，不能保留过期的已加载提示。Markdown 保持来源和版本，原文不自动翻译。
- 使用原生按钮、输入、选择和 dialog。桌面按钮至少 34px，窄屏主要按钮至少 44px；焦点可见，Esc 关闭后归还焦点。
- 表单桌面合理双列、窄屏单列；字段具名，署名和许可不藏在登录之后。
- 中英日使用同一布局，设置即时切换；语言文件在根目录 languages。资源内容保持作者原文。
- 下载和 Star 为有来源的数值，收藏和评分为个人状态，未知数值不填零；详情和列表共享组件。

没有新增动效。现有浏览器验收覆盖宿主样式隔离、主题、字号、多语言、窄屏和文档读取；不声称已完成完整 WCAG 认证。
