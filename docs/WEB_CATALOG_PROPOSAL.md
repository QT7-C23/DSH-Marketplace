# 公开资源浏览站建议

日期：2026-09-13。状态：乙方建议，尚未作为网站开发或部署的授权。甲方希望用户能更方便地查看各类资源。

## 建议与用户价值

建议建设公开浏览站，作为 DSH 内市场的补充。用户无需安装 DSH 即可搜索资源、阅读用途与许可、分享详情链接，并通过 GitHub 推荐内容或申请移除。实际安装、配置、调用及已安装资源管理继续在 DSH 内完成；网站不替代完整的宿主市场与管理体验。

## 第一版范围

- 支持插件、Skill、MCP、Slash、Prompt 五类筛选、搜索和可分享的详情页。
- 展示真实来源、原作者、固定版本、许可、依赖、已验证能力及目录更新时间。
- Prompt 可预览和复制；其他资源提供经过核对的获取方式及 DSH 使用说明。
- 提供投稿、问题反馈、移除申请入口，复用本仓库的 GitHub 表单与 PR 流程。
- 浏览无需新账号；界面提供英、中、日切换，资源原文与界面翻译分开。

当前尚未验证 DSH 的外部深链接或浏览器一键安装协议，因此首版不承诺“点击网站就自动安装”。来源仓库 Star 可作为独立指标；本机下载、收藏和评分不能汇总成网站公共统计。没有可靠公共数据时显示暂无数据。

## 内容与更新方式

网站和 DSH 共用 `catalog/prompts/`、`catalog/index.json` 与 `sources/catalog.json` 的资源身份和版本资料。维护者审核投稿并更新规范目录，网站由同一份公开快照生成，避免手工维护第二份名单。自动发现新资源仍是独立待实现能力，不能通过增加网页宣称完成。

目录发布还需明确刷新时间、失败保留、资源撤回与重现处理。核实移除申请后，应同步更新网站与后续 DSH 目录；未来自动发现必须尊重已确认的移除记录。已下载到用户本机的副本无法通过网站保证远程删除。

## 托管与顺序

第一版可评估 GitHub Pages：它从仓库发布静态 HTML、CSS 和 JavaScript，公开仓库可使用 GitHub Free，无需先购买独立域名或租用服务器。它适合公开目录浏览，账户、公共评分、可信下载统计及服务端操作仍需另外设计。[GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

建议顺序：先完成仓库首次发布与投稿模板，随后落实同源目录的发布、更新和撤回机制，再交付网站的浏览闭环。验收至少覆盖真实数据、三语导航、手机布局、可分享链接、更新与撤回一致性，以及清楚可用的 DSH 使用说明。
