# README 语言与按需翻译

## 本轮要求与实现

中文界面优先中文 README，没有时回退英文；英文和日语界面同样按其语言优先。识别常见语言文件名，在三份文档读取上限前保留中英日首选文件。手动切换仍可用，原始文本完整保存，文件头部元数据不作为正文显示。

作者文档新增“翻译文档”：展开只读取宿主模型列表，选择服务商、模型和目标语言后，点击“开始翻译（消耗 Token）”才调用。默认显示宿主默认模型，也允许选择其他已配置模型。明确提示正文发送、Token 额度和失败/取消可能计费；译文标注目标语言与模型，可切回原文。用量来自服务商，缺失不填零。

实现使用锁定版本 DSH 的公开模型服务，来源为 [dsh-llm 官方文档](https://github.com/deepseek-ai/deepseek-harness/blob/c291e7961a515f6d7af9304e7fd1d257929aef26/packages/llm/llm/README.md) 及本地发布包类型与实现。只发送当前原文，不关联会话、工具或工作区资料；原文中的指令作为待翻译内容。具体边界见 [架构](../ARCHITECTURE.md)。

## 验收记录

先增加失败回归：界面语言优先、语言目录截断、翻译模型/文档绑定、Token 报告、拒绝未经确认请求、错误结束帧及取消。修复后相关行为测试通过。

真实宿主的翻译用隔离测试适配器验证，没有付费模型凭据。覆盖模型选择、开始前无调用、双击只一次、费用提示、原文切换、服务商失败、取消传递、换资源隔离及窄屏。测试适配器只由统一验收的临时配置显式注册，普通启动不加载它。

首轮全宿主验收在现有来源下载测试遇到网络等待超时；定向验收已确认翻译成功与取消工作，另发现旧 Skill 文档断言依赖头部元数据，已改为检查实际正文并确认原始视图仍保留元数据。完整 `npm run verify` 随后通过 83 项（62 项基础、7 项文档/翻译、14 项真实宿主），证据在 artifacts/dsh-integration/verify-u2RzBx。最后文档排版复核补测普通 Markdown 分隔线不应误判为元数据；修复后再次运行统一门禁。
