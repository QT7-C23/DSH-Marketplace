# DSH 原生风格与游客流程验收

日期：2026-09-13。甲方认可 [风格与身份复核](2026-09-13-market-style-and-identity.md) 后实施，范围为现有市场改版与免市场登录的获取/本机使用流程。

## 已实现

- 改为发现 / 我的资源双层导航，提供搜索、五类筛选、真实排序与卡片；分享和来源设置降为次级入口。
- 根据甲方实施中的补充，保留市场特色与精选横幅：暖色渐变和周报预览，点击进入真实模板流程；搜索或筛选时收起推荐。此前完全移除横幅的方案不再作为最终要求。
- 宿主样式直接消费 DSH 的颜色与字体变量；Prompt 正文随宿主字号调整。本项目使用薄 HTML 控件，未直接导入上游 React primitives 包。
- 浏览、公开版本下载、Prompt 使用、本机收藏与新投稿草稿不要求市场账户。发布、评分、反馈与主动同步时说明身份用途。
- 本机收藏与账户收藏分开；已有账户数据保留，登录不自动同步。登录保留游客投稿，退出保留本机内容并清理账户私有视图。
- 游客下载仅可获取当前公开版本，持久化请求摘要去重；重试再次检查公开状态。撤回资源的本机副本仍可导出和使用，不增加社区下载量。
- 本机存储失败不标记成功；损坏数据不覆盖；检测到其他页面已修改存储时拒绝覆盖并提示刷新。

## 验证

新增游客下载、本机持久化、存储失败及推荐入口的回归检查，先观察预期失败再实现。实际浏览器覆盖双账户旧流程、游客从下载到 Prompt 使用、撤回后的本机导出、刷新恢复、投稿中途登录不丢内容、深浅主题、390px 重排、Esc/焦点及实际字号设置。会话引用、附件和后续新输入保留的原测试继续执行。

统一入口：`npm run verify`，包含 35 项原型/数据/适配器测试和 8 项实际 DSH 浏览器测试，以及类型检查、插件构建、静态边界与原型 26 组对比度检查。

最终统一验证全部通过，隔离运行证据位于 `artifacts/dsh-integration/verify-Us9XT7/`。已人工查看最新首页与窄屏截图；截图分别为 `artifacts/dsh-integration/host-market.png`、`community-dark.png` 和 `community-mobile.png`。手动预览继续使用原 `debug-community` profile 和 4181 端口，原社区数据库保留。

## 数据与完成边界

本机存储键 `dsh-market-local-v1` 按浏览器与站点地址（含端口）保存；清理站点数据会丢失。本机内容不按市场账户隔离。账户草稿和账户收藏仍保存在原 SQLite 数据库；新增公开下载请求表，不迁移或删除原表。

DSH 自身访问认证保留。当前仍是本机开发版本，没有公开部署、OAuth、账户找回或审核后台。其他四类只支持说明资料的分享、收藏与导出，安装、加载、连接和执行仍未接入。独立原型保留旧视觉，当前产品体验应使用真实宿主入口。完整无障碍认证、忙碌会话和跨版本兼容仍待验证。
