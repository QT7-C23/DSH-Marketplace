## 3. 解决的实际问题

DSH 的 HTTP 桥接把 URL 表示为 `http://dsh.internal`；直接用于 Origin 比较会拒绝正常同源请求。适配器现在采用经过 DSH 信任检查的 Host。该桥接的 GET 流式请求还会产生带正文的 GET Request，导致空的 400 响应，因此将读取与写入分开注册。空响应和非法 JSON 也会转换成可操作的中文错误。

控制器增加请求代次，避免账户切换后迟到数据恢复旧身份；保存请求携带查看版本，避免点击后资源变化却静默保存新版。投稿重试保留请求编号，服务端通过事务和结果表去重。这些问题均先增加失败测试，再实现修复。

窄屏验收最初在宿主侧栏折叠动画尚未完成时读取了布局，错误地只给市场约 117px 空间；修正为等待宿主实际完成收起，再检查 390px 视口中的市场重排，没有用隐藏溢出来掩盖问题。

## 4. 统计口径

收藏为当前保存人数；评分为非作者账户的一份可修改评分，显示平均值和人数，没有评价时显示“暂无评分”。两者按资源汇总，不按每个版本拆分。下载累计生成资料文件的有效请求，重试去重；它不代表最终落盘成功或独立人数。Prompt 下载文本，其他四类下载说明 JSON，页面不将它称为安装包下载。精选来源样本没有本社区行为记录，不展示虚构热度。
