# 贡献指南参考与独立审核原则

日期：2026-09-14。对应 R32：甲方认可外部指南的组织方式，但明确其收录条件只作参考。

## 核查与取舍

阅读 [Awesome DSH Plugin 贡献指南](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin/blob/main/contributing.md) 的投稿、条件、人工评审、截图和更新章节。该链接随上游更新；这里记录的是核查当日的内容。尝试浅克隆以研究原文件时 GitHub 连接失败，已通过浏览器文本读取完整指南，没有运行上游脚本。

| 参考内容 | 本项目的处理 |
|---|---|
| 投稿步骤、所需材料、反馈分别说明 | 用现有 GitHub Issue/PR 流程写清，接受修改和补材料 |
| 插件安装声明与功能证据 | 限定在插件对应的能力声明，不对 Prompt 等文字资源要求 manifest |
| 仓库年龄、Topic、固定 PR 数量 | 不引入这些门槛；依据实际审核工作拆分投稿 |
| 分类与已有条目判断 | 允许有明确差异的同类资源并存，分类可在审核中调整 |
| 截图说明 | 推荐作为审核材料；不照搬其图片字段、数量限制或承诺自动获取 |
| 自动检查与人工判断 | 记录本仓库现有校验能力，不声称已接入对方 CI 或自动批准 |

## 本次改动

`CONTRIBUTING.md` 三语部分增加一致的共同材料、五类审核说明、证据阶段和反馈流程。引用当前 Prompt 文件格式、来源适配器限制及移除说明，避免同一技术规则出现多个事实源。明确资源的适用性和市场当前的接入能力是两个判断。

资源 Issue 表单链接本项目指南，允许原创 Prompt 说明新投稿而非另建仓库；补充可选的分类材料。PR 模板提醒提供实际验证阶段。目录说明与来源说明同步链接独立审核依据，产品计划增加 R32。没有修改资源准入代码、下载白名单、许可范围、现有条目或官方安装方案；没有推送或发布模板。
