# 主题分类与版本协议核查

对应 R33、R34。日期：2026-09-14。当前结论与交付边界统一在 [资源兼容与主题支持](../COMPATIBILITY_AND_THEMES.md)，此文件只记录本轮工作。

## 证据与取舍

- 官方上游 `master` 已描述 `engines.dsh` 与 `dsh.manifestVersion`，并说明当前安装器/加载器不强制执行。锁定 npm `0.1.5-rc.2` 的公开类型尚无这些新增字段；网页说明不能替代安装包事实。
- 直接读取 npm 元数据：adapter-dsh 的 `latest` 为 `0.1.1-rc.2`，`rc` 为 `0.1.1-rc.3`。后一版本声明支持当前宿主所在的版本线，固定发布提交 `83eee7fdb3e3096005bb6aeded1e7b6458727d35` 的变更记录也明确 DSH 0.1.5 对齐。初次读取的默认分支网页仍显示旧内容，因此改查发布元数据和固定提交，避免误判。
- 本地两份锁文件及运行插件源码均未发现 dsh-std 依赖；本轮没有安装适配器、改变宿主版本或声明跨版本验收通过。
- 主题以独立市场类别呈现，底层区分插件与配色文件。原生主题 token 接口存在，但现有市场还没有审核后的主题条目或应用流程。

## 实现范围

共享资源合同、历史原型类型、宿主分类和投稿表单加入主题；三语类别说明、主题审核提示、图标、使用步骤和空状态同步。主题投稿保留原作者、来源、许可和正文，依然只导出 GitHub 建议文件。普通 Skill 的 theme-factory 保持 Skill 分类。

三语 README、贡献指南、Issue/PR 模板、产品计划、流程及来源说明同步。版本要求与实测结果分开记录；没有把外部标准当作必选条件，也没有放宽既有下载来源或许可校验。
