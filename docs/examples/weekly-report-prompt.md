# 周报整理 Prompt：流程评审样本

版本：0.1｜来源：本项目自编｜状态：可手工填写的模板，尚未验证生成效果或商城接入。

用途：把用户提供的工作记录整理成周报草稿。下列双花括号仅表示待填位置，不是已经实现的 DSH 模板协议。分享的是模板与虚构示例，用户自己的工作内容不随投稿上传。

## 模板正文

```text
请根据我提供的记录，整理一份简洁、客观的中文周报草稿。

报告周期：{{报告周期}}
本周记录：{{本周记录}}
下周计划：{{下周计划}}

请分为“本周进展”“问题与待确认事项”“下周计划”三部分。
只使用已提供的事实，不编造完成情况、数据、负责人或承诺日期。
区分已完成、进行中和受阻事项；缺少必要信息时标注“待补充”。
未明确完成的事项不要写成已完成；计划不要写成已经发生的结果。
保留会影响判断的问题，用简短条目表达，供我检查后再使用。
```

## 虚构示例输入

| 待填项 | 示例 |
|---|---|
| 报告周期 | 第一次内部试用周 |
| 本周记录 | 已完成三份使用说明；资源详情页仍在制作；连接测试因缺少测试账户尚未开始 |
| 下周计划 | 完成详情页草稿，补齐测试账户后开始连接测试 |

## 检查依据

- 周报应准确保留“三份使用说明已完成”。
- 详情页应保持进行中，连接测试应保持尚未开始并说明原因。
- 不应新增满意度、节省时间、完成百分比、负责人或具体交付日期。
- 输入为空时应在填写阶段提示；这一产品行为仍需未来实现与测试。

模板更新样例可用于核查作者版本与用户副本的区别，不能据此声明已经有发布、更新或恢复功能。
