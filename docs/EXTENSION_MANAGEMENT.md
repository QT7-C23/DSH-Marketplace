# 扩展、Skill 与 MCP 管理

适用于 `v0.2.0-alpha.1`。安装入口见[安装指南](PACKAGE_INSTALLATION.md)，其他文档见[文档目录](README.md)。

本页描述已实现的流程与冷启动要求。`v0.2.0-alpha.1` 标准组件经过五次真实进程和 Edge 验收，包含卸载准备、官方卸载后原组件继续运行。[商城安装](PACKAGE_INSTALLATION.md)

## npm 插件与主题

1. 在资源详情或“已安装扩展”选择完整包名和精确版本，点击检查。预览读取实际 npm 元数据与发布包，核查 SRI、声明和入口，不执行其代码。
2. 核对目标 profile、许可证、已声明权限、宿主／Node 版本范围、依赖和接入方式。未知兼容性保持未知，已知不兼容阻止执行；普通内部模块不能因为存在于目录就重复安装。
3. 明确执行后，由可信的 CLI 路径和参数数组调用：

   ```text
   dsh plugin --profile <profile> add <name>@<version> --ignore-scripts --save-exact --registry=https://registry.npmjs.org
   ```

   HTTP 请求不能指定 profile 路径、可执行程序或任意 shell 命令。安装器保存备份并核对配置指纹、直接依赖、实际安装包与 bundle。
4. 按结果提示重启 DSH 并刷新浏览器，再看实际加载状态。更新选择新的精确版本重新预览；卸载由官方 `remove` 执行。
5. 原生入口的启停使用公开 Loader 条目和 profile patch，保持原配置字段／表达式与入口归属，不删除包来代替停用。

受保护的 DSH 基础包、市场自身及共享适配器不能通过普通管理操作破坏；存在直接反向依赖时拒绝相应变更。已安装在市场之外的包仍按真实库存识别，无法确认归属或存在冲突时拒绝写入。主题遵循其包接入方式，已知实测问题见 [主题结果](COMPATIBILITY_AND_THEMES.md)。

当前安装预览仅支持 npm 官方精确版本，压缩包上限 4 MiB、解压 32 MiB。任意 URL、本地路径、版本范围以及同时声明原生／标准入口的包不走该安装入口。商城自身的官方本地 TGZ 安装是 [独立流程](PACKAGE_INSTALLATION.md)。

预览 SRI 与执行记录绑定；官方 CLI 按名称、版本重新获取发布物，不是将预览字节直接交给 pnpm。锁文件记录传递依赖，这不等于完整供应链审计。

## 标准组件：先经过冷启动，再按下次启动管理

一个市场管理的 Loader 向公开 SDK 提交完整启用集合，由 SDK 发现、导入并挂载组件。关闭的包不进入该集合，不通过私有句柄逐个卸载模块。禁用策略按 npm 包身份保存，跨版本更新和暂时移除保留；外部正常安装的适用包在下一次初始化进入集合。

**首次接管有单独的进程边界。** 接管把原核心配置改为 `discover: false` 并写入市场 Loader；监视器可能重载核心和全部标准组件。执行前会提示这一影响。公开 SDK 无法证明旧发现批次已彻底清理，因此首次接管后的同一宿主进程始终显示 **unknown／restart-required**，并拒绝下一次标准组件启停。即使替换后的适配器显示 active，也不能视为接管完成。必须完整停止并重新启动宿主。

正常启动后的稳定 Loader 才接受后续控制：

- 预览复核精确安装版本、文件绑定、核心／Loader 配置、运行时身份、活动代次及 profile 指纹。
- 启用检查组件所需协议；停用检查反向依赖和移除目标后仍需满足的声明。
- 写入 `disabledPackages` 只改变持久化目标状态。活动 Loader 阻止配置更新引发的立即重新初始化，当前挂载批次不变；下次启动才按新的集合发现。
- 界面分开显示目标与实际状态。重启 DSH 后还需刷新浏览器客户端，才确认界面与功能变化。四进程实测已覆盖首次接管未知、冷启动后 A 停用而 B 的命令／界面可用、同进程启用意图不改当前批次、下次启动 A 恢复，以及停用 A 更新到 2 后仍不导入和外部新增组件正常加载；候选版本已复跑通过，并增加市场卸载后的第五次启动验收。

这不是绝对生命周期冻结：依赖失败、核心变更、显式释放及失败／加载中的 fiber 仍可能导致重新初始化并读取最新配置。没有进程内模块缓存重置、逐包热替换或浏览器热移除。可识别的重复／未知发现所有者、路径重定向、入口冲突或不确定清理状态阻止后续操作；没有自动接管私有运行时或自动恢复。

## Skill 原始文件生命周期

资源必须来自当前目录中的审核固定提交，带原始文件、SKILL.md 与许可清单。安装将完整校验的文件放入 `DSH_HOME/skills/<name>/`；继承许可保存在受管理的许可位置，原字节不改写。状态再通过原生 Skill 注册接口核对实际来源，区分 installed、loaded、shadowed、modified、unavailable 等情况。

- **启停**：完整目录在原生根与私有 disabled 区之间移动，保留原始字节；目标被外部文件占用或现有内容被修改时拒绝。
- **更新**：仅接受同一仓库／根身份的更新修订，先下载、校验完整新版本，再移动替换；旧版保留。
- **移除**：文件进入私有 recovery 区，可恢复；不等于擦除。原本停用的资源恢复后仍保持停用。
- **恢复**：核对现存副本、回执和事务记录后恢复已保留版本或处理可恢复中断。界面展示实际恢复的修订，可能比目录当前版本旧。

私有记录在 `DSH_HOME/community/skill-files/`，包含回执、锁、事务、停用及恢复内容。校验覆盖路径／目录身份、无链接边界、文件模式、Git blob 和实际 SHA-256；非本市场管理的目录、额外文件或无法验证的内容均予以保留。最多保留 16 个前驱版本，达到上限需人工处理；不擅自清理历史。

两次目录重命名间可能短暂无原生目录，不承诺无间断原子交换。已有会话内容和缓存不是文件删除的附属品；原生加载与调用须按实际宿主状态确认，需要时重启再检查。记录中的 42 项文件／传输回归和六次实际宿主启动验证有各自范围，不构成断电、恶意同用户并发替换或所有 Skill 功能的保证。

## MCP 连接

从资源详情读取完整固定 `serverDefinition`，选择受支持的连接，填写声明变量、请求头、环境值和参数，再明确连接。当前支持公共 DNS 的 **HTTPS Streamable HTTP**，以及 npm 官方注册源的 **精确版本 stdio**。npm 启动固定包和可信运行器；不接受自定义运行参数绕过版本固定。目录可收录其他 stdio 定义，但 UI 会如实列出不支持的连接选项。

连接写入明确归属的 profile 配置，并经过共享安装器的指纹、备份和锁。可启用、停用、移除；只操作自身归属项，配置被外部修改时停止。凭据可能保存在宿主配置和本机备份中，公开状态不返回秘密值。

`configured`、`connecting`、`registered`、`disabled`、`failed` 等状态分别展示；工具名来自宿主实际注册表。**registered 只证明工具注册，不能证明服务持续健康或每次调用成功。** Microsoft Learn 公开服务的实际搜索和跨启动启停／移除已验证，其他服务按其要求与实际调用结果判断。

更改参数、凭据或服务版本时，先移除旧连接，再用新定义明确连接。当前不提供原位配置／版本替换或自动凭据迁移；复制目录定义和下载 JSON 都不会自动连接。

## 操作历史、中断与人工恢复

“操作历史”显示最新 **20 条**经过筛选的 profile 操作元数据：操作编号、动作、包／配置名称、阶段和时间，以及当前阻塞编号。它不显示完整日志、备份、配置路径或秘密值，也不代替 Skill 私有版本历史。

profile 操作记录位于 `DSH_HOME/community/operations/<operation-id>/`，包括 `journal.jsonl`、`cli.log`、`backup.json` 与 `backup/`。备份覆盖 `package.json`、`pnpm-lock.yaml` 和 `cordis.patch.yml`，不包含完整 node_modules、缓存、会话或插件数据。

失败、超时、中断或后置核验不一致时可能保留 `.dsh-market-installer.lock` 并进入 recovery-required。Skill 使用自己的按名称锁；进程死亡同样不会自动解除。取消不是回滚证明。预览十分钟有效，内存去重不跨重启；锁能串行化受管理操作，不能阻止独立编辑器或其他 CLI 改文件。

恢复时先停止对应宿主，确认 CLI／pnpm 等相关进程结束，按操作编号检查当前配置、依赖、日志与备份，保留中断后的外部修改。完成修复并验证归属、安装／加载结果后，才可人工移除已确认无主的锁。Skill 的明确恢复也不绕过锁。**没有一键恢复、自动回滚或自动解锁**；不能靠删锁声称恢复成功。

统一验证入口为 `npm run verify`。本页不把局部回归、历史混合运行检查或配置写入成功升级为最终候选版验收结果。

标准组件卸载边界与上游 CommandRuntime 组合限制见 [安装说明](PACKAGE_INSTALLATION.md)。
