# 首版使用流程与开发顺序

更新：2026-09-14，依据 [产品方案](PRODUCT_PLAN.md) R17—R34。主题恢复为第六类，模型与 Cookbook 暂缓。市场没有账号，社区投稿由 GitHub 承接。

## 作者流程

1. 选择类型，填写名称、用途、版本、原作者、许可、来源与原文语言。
2. 编写内容或导入文件，保存含署名的本机草稿。
3. 预览并导出 JSON；导出不等于上传。
4. Prompt 通过 PR 加入 catalog/prompts，其他类别在资源提交 Issue 附文件、README、要求和实测。
5. 维护者核对来源、许可、重复条目与兼容性后收录；修改仍通过 GitHub，未接通在线自动同步。

表单署名不是身份核验；不另建市场登录、密码或账户维护。

## 使用者流程

| 类别 | 当前可以完成 | 仍缺的实际生效环节 |
|---|---|---|
| 插件 | 发现 → 概况/自身 README → 下载校验 TGZ → 收藏 | 安装、启停、升级恢复 |
| Skill | 自动发现 → 概况/SKILL.md → 下载完整校验 ZIP → 收藏与明确更新 | 提供者配置、加载、调用 |
| MCP | 发现 → 概况/仓库 README → 下载原始服务定义 | 转换 DSH 配置、身份、连接与调用 |
| Slash | 发现 → 命令说明 → 所属插件文档/包 | 宿主注册、参数和执行 |
| Prompt | 发现 → 原始提示词 → 下载或填参 → 预览 → 追加 DSH 草稿 | 用户自行发送；输出质量未评估 |
| 主题 | 类型筛选、三语使用说明、署名投稿与 JSON 导出；暂无已审核条目 | 真实主题来源、插件或配色文件获取、应用、重启与恢复 |

规划插件与 /plan 共用发布包；internal-comms 保留 examples 和许可；Microsoft Learn 导出原始服务定义；Code Reviewer 保留 rajudandigam 署名和 CC0 原文。自编周报和 Filesystem MCP 仍标为示例。

## 页面与数据

- **发现**：短概况、资源类型和用途分类；搜索或筛选时收起横幅。
- **详情**：概况与作者文档；有来源、提交和原始内容。缺少 README 与读取失败不同。
- **我的资源**：本机收藏、个人评分、草稿和更新；副本不会被目录更新直接覆盖。
- **设置**：中英日界面语言、来源数量、扫描报告、自动检查与手动更新。
- **分享**：六类统一署名表单，导出后前往 GitHub；主题补充形态、父插件、适用版本与恢复方法。

下载量为本机服务准备文件的次数，Star 是整个仓库，收藏和评分为个人数据；不显示伪造的社区人数或均分。

## 自动发现与后续

Anthropic 当前扫描 19 项、收录 12 项；新增名称自动进入目录，不满足许可或大小条件的条目显示原因。每 6 小时检查，失败保留目录并在 30 分钟后重试；暂停持久化，恢复触发检查。自动发现不会安装或执行。

DSH 与 MCP 仍更新指定条目。继续扩展其他来源与新仓库搜索，再按真实资源逐类接通安装、加载、连接、命令执行和恢复；随后完善目录发布与社区投稿同步。公开浏览站仍是单独建议，未部署。

统一执行 `npm run verify`，区分本机数据、来源网络、文件校验和宿主行为；不调用模型或公开发布测试稿件。当前证据见 [本轮记录](research/2026-09-13-discovery-languages-and-docs.md)。
